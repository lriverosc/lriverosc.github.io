## Variantes
- `dark_bg`: optimizada para fondos oscuros (trazo principal blanco + acento cian/índigo).
- `light_bg`: optimizada para fondos claros (trazo principal azul marino + acento cian/índigo).

## Formatos
- SVG vectorial editable.
- PNG transparente 1024 × 1024 px.
- PNG transparente 512 × 512 px.

Todos los PNG tienen fondo transparente. Las imágenes `preview_*.png` son solamente hojas de muestra.
